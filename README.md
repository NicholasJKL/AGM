# Введение

В эпоху компьютерных технологий многие математические понятия обрели новую жизнь. Арифметико-геометрическое среднее не исключение.  Этот метод, изученный ещё Гауссом в конце XVIII века, не только демонстрирует элегантность сходимости, но и служит мостом между решением математических задач и компьютерными технологиями.

Благодаря высокой скорости сходимости алгоритм арифметико-геометрического среднего идеально адаптирован для одновременно быстрых и точных расчётов, что необходимо при решении задач, сводящихся к решению эллиптических интегралов.

Таким образом, арифметико-геометрическое среднее служит ключевым инструментом в современных инженерных и научных решениях, позволяя упрощать моделирование, вычисления и анализ.

# Теория
## Арифметико-геометрическое среднее

**Арифметико-геометрическое среднее (АГС)** – величина, определяющаяся для двух чисел a и b в итеративном процессе, где на каждом шаге вычисляются арифметическое и геометрическое средние двух чисел:  

$`
a_0 = a, \quad b_0 = b;
`$  

$`
a_{n+1} = \frac{a_n + b_n}{2}, \qquad b_{n+1} = \sqrt{a_n b_n};
`$  

Которые постепенно сближающиеся к общему пределу:  

$`
\text{АГС}(a,b) = \lim_{n \to \infty} a_n = \lim_{n \to \infty} b_n.
`$  

АГС применяется в вычислении полных эллиптических интегралов первого рода, которые возникают при решении широкого круга задач.

## Модифицированное арифметико-геометрическое среднее

**Модифицированное арифметико-геометрическое среднее (МАГС)** – величина, определяющаяся для двух чисел a и b в итеративном процессе, где на каждом шаге вычисляются три последовательности:  

$`
a_0 = x, \quad b_0 = y, \quad c_0 = 0;
`$  

$`
a_{n+1} = \frac{a_n + b_n}{2},
`$  

$`
b_{n+1} = c_n + \sqrt{(a_n - c_n)(b_n - c_n)},
`$  

$`
c_{n+1} = c_n - \sqrt{(a_n - c_n)(b_n - c_n)}.
`$  

Пределы последовательностей a и b, как и в АГС, сводятся к общему:

$`
МАГС(a, b) = \lim_{n \to \infty} a_n = \lim_{n \to \infty} b_n.
`$  

МАГС в связке с АГС позволяет эффективно вычислить значение полного эллиптического интеграла второго рода.

# Программная реализация

Для автоматизации вычислений была создана программа, реализующая методы арифметико-геометрического среднего и модифицированного арифметико-геометрического среднего для решения практических задач:

1. Расчёт периода математического маятника.
2. Расчёт периметра эллипса.
3. Расчёт численных значений волнового уравнения с предустановкой функции начальных возмущений (график).

---

Программный модуль с вычислением АГС и МАГС может выступать в качестве библиотечной функции для эффективных расчётов.
